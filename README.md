# shapeipv4

Shape URLs and ipv4 query parts with stable normalization.

**Site:** https://theworker02.github.io/shapeipv4/

## Install / run

```bash
git clone https://github.com/theworker02/shapeipv4.git
cd shapeipv4
node src/cli.js
node --test
```
